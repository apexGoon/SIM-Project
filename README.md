# Security Incident Mapping (SIM)

## Overview

Security Incident Mapping (SIM) is a web application that allows students, staff, landlords and residents to report security incidents around the campus.

## Objectives

- Improve campus security
- Enable quick incident reporting
- Store security reports
- Help security officers respond faster

## Features

- Home page
- Incident reporting form
- Success page
- Responsive design

## Technologies Used

- Python
- Flask
- HTML
- CSS
